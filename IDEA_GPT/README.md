# IDEA_GPT — GPT 아이디에이션 인박스

## 이 디렉토리는 진실이 아니다

검증되지 않은 원문이다. 여기 있는 내용을 근거로 인용하지 않는다.
`IDEA_RESOLVED/` 로 승격된 뒤에야 근거가 된다.

## 쓰는 주체

**GPT 데스크탑 또는 Codex** 만 쓴다. Claude Code 는 읽고 승격하되 여기에 쓰지 않는다.

디렉토리마다 쓰는 주체가 하나이므로 동시 쓰기 충돌이 구조적으로 생기지 않는다.

## 출처 머리글 (권장)

파일 맨 위에 4줄:

```
출처: gpt-desktop | cowork | codex
작성: YYYY-MM-DD
맥락: 무슨 논의에서 나왔나 (한 줄)
지위: 제안 | 승격요청
```

앱이 이 형식을 안 지켜도 된다 — **승격 시 Claude Code 가 정규화한다.**
규칙을 앱에 기대는 설계는 표면이 늘어나면 깨지므로 이중 안전망으로 둔다.

## 파일명

권장: `YYYY-MM-DD-<주제-슬러그>.md` · 안 지켜지면 승격 시 정규화.

## 덮어쓰기

같은 파일을 앱에서 계속 고쳐도 된다. 단 **커밋 안 된 상태에서 덮어쓰면 이전 버전이
사라진다.** Claude Code 가 세션 시작 시와 승격 시 이 디렉토리를 커밋하므로,
한 번 커밋된 뒤로는 `git diff` 로 복구 가능하다.
